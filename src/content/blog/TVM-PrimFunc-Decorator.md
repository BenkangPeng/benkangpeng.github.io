## Summary: The Complete Picture

1. **`@T.prim_func`** decorator wraps your function
2. **`parse()`** is called with your function
3. **Parser** converts Python source → Python AST
4. **IRBuilder** context is created (`builder.frames = []`, `builder.result = NullOpt`)
5. **`visit_function_def()`** is called, which:
   - Creates `PrimFuncFrame` and enters it (pushed to `builder.frames`)
   - Parses function arguments (calls `T.arg()`)
   - Parses function body statements recursively
6. **Each statement** creates corresponding IR builder calls:
   - `A = T.match_buffer(...)` → adds to buffer_map
   - `with T.block(...)` → creates BlockFrame
   - `C[vi, vj] = ...` → creates BufferStore
   - `for i, j, k in T.grid(...)` → creates ForFrame
7. **Nested frames** build IR from inside-out as they exit
8. **`PrimFuncFrame` exit** constructs the final `PrimFunc` and stores it in `builder.result`
9. **`builder.get()`** retrieves and returns the `PrimFunc`

The key insight: **The parser walks the Python AST and calls/eval IR builder functions (like `T.prim_func()`, `T.arg()`, `T.block()`, etc.) which use the frame-based IR builder system we discussed earlier to construct the TVM IR!**
